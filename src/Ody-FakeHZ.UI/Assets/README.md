# Assets Folder

## Tray Icon

The system tray icon should be placed here as `tray-icon.ico`.

**Icon Requirements:**
- Format: .ico (Windows Icon)
- Size: 16x16, 32x32, 48x48 (multi-resolution)
- Design: Monochrome (black/white/gray)
- Style: Simple "Hz" symbol or frequency wave

**Temporary Solution:**
Currently using default system icon. Replace with custom icon for production release.

**Icon Design Ideas:**
1. Stylized "Hz" text in monochrome
2. Frequency wave pattern
3. Monitor with motion lines
4. Abstract interpolation symbol

Create the icon using tools like:
- GIMP (free, can export .ico)
- Inkscape (vector, export to .ico)
- Online ICO converter tools
